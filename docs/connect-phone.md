# Подключение телефона как камеры (IP Webcam)

Эта инструкция превращает обычный Android-телефон в IP-камеру, с которой наш сервер
забирает кадр раз в 10 минут по адресу `http://<ip-телефона>:8080/photo.jpg`.

## Что нужно
- Android-телефон и ПК, подключённые к **одной и той же** Wi-Fi сети (один роутер, один SSID).
- Зарядка (телефон будет работать постоянно).
- На ПК ничего доустанавливать не надо: забор кадра делает наш скрипт через стандартный HTTP.

## Шаги
1. Установи приложение **IP Webcam** (автор Pavel Khlebovich) из Google Play.
2. Подключи телефон к тому же Wi-Fi, что и ПК. Важно: это должна быть основная сеть, а не
   «гостевая» — в гостевых сетях часто включена изоляция клиентов, и ПК не увидит телефон.
3. Открой IP Webcam, пролистай в самый низ и нажми **Start server**.
4. На экране появится адрес вида `http://192.168.1.50:8080`. Это и есть нужный IP.
5. Проверка с ПК: открой в браузере `http://192.168.1.50:8080` — должна открыться страница IP Webcam.
   Готовый кадр (снимок) лежит по адресу `http://192.168.1.50:8080/photo.jpg`.
6. Проверка командой на ПК:
   ```bash
   curl -o /tmp/test.jpg http://192.168.1.50:8080/photo.jpg
   ```
   Если файл скачался и это фото растения — связка работает. Этот адрес и есть `source_url`
   в `configs/capture.yaml`.

## Как узнать IP, если не видно в приложении
- В самом IP Webcam адрес показан на главном экране после **Start server**.
- На телефоне: Настройки → Wi-Fi → твоя сеть → «IP-адрес».
- В админке роутера: список DHCP-клиентов.

## Если страница не открывается с ПК
- **Разные сети / гостевой Wi-Fi** → подключи телефон и ПК к одной основной сети.
- **Файрвол на ПК** → разреши доступ для локальной сети (Linux Mint обычно не мешает в LAN).
- **VPN** на телефоне или ПК → отключи на время настройки.
- **Разные подсети** (например, 192.168.0.x и 192.168.1.x) → должны совпадать первые три числа.

## Чтобы адрес не менялся со временем
- В настройках роутера задай **резервирование DHCP (static lease)** для телефона по его MAC-адресу.
  Иначе при перезагрузке роутера IP может измениться, и `source_url` в конфиге сломается.

## Постоянная работа (фоновая съёмка)
- Держи телефон **на зарядке** всё время.
- Отключи оптимизацию батареи для IP Webcam: Настройки → Приложения → IP Webcam → Батарея → «Без ограничений».
- Не закрывай приложение; при блокировке экрана сервер обычно продолжает работать, но некоторые
  прошивки его останавливают — проверь на своём телефоне.
- Съёмка идёт только в световое окно (по умолчанию `06:00-22:00`); ночью кадры пропускаются
  (фотопериод растений, настройка `light_window` + `dark_policy` в `configs/capture.yaml`).

## Что прислать для включения системы
- Адрес вида `http://192.168.x.x:8080` — он вписывается в `configs/capture.yaml` как `source_url`,
  после чего включается таймер systemd на 10 минут и делается первый реальный кадр.

## Как закрепить адрес телефона (DHCP reservation)
1. Открой веб-интерфейс роутера (обычно `http://192.168.1.1`).
2. Найди список DHCP/LAN-клиентов.
3. Найди телефон по его MAC-адресу (MAC виден в IP Webcam и в настройках Wi-Fi телефона).
4. Добавь статическую арену (static lease), привязав этот MAC к `192.168.1.5`.
5. Сохрани настройки.

Если роутер не умеет резервировать адрес — при смене IP у телефона нужно обновить
`source_url` в `configs/capture.yaml`.
